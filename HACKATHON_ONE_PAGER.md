# 🎓 EduGap - One-Page Overview

---

## 🎯 What is EduGap?

**AI-powered educational platform that identifies student learning gaps through diagnostic quizzes and provides personalized remediation using real-time AI generation.**

---

## 💡 The Problem → Solution

| Problem | Solution |
|---------|----------|
| Students don't know their weak areas | AI-generated diagnostic quizzes |
| Generic study materials don't help | Personalized AI remediation |
| No performance feedback | Real-time failure risk analysis |
| Expensive AI tools | Completely free (Groq API) |

---

## 🚀 Key Features

### 1️⃣ AI-Generated Quizzes
- Unique questions every time
- 4 subjects: Physics, Chemistry, Math, Biology
- 5 questions per quiz
- Generated in 2-3 seconds

### 2️⃣ Real-Time Analysis
- Exam failure risk % (0-100)
- Weak concept identification
- Personalized AI summary
- Actionable recommendations

### 3️⃣ Personalized Remediation
- Concept-specific explanations
- Worked examples with solutions
- Study resources
- YouTube video recommendations

### 4️⃣ Context-Aware Chatbot
- Available on 3 pages
- Knows your subject & performance
- Answers study questions
- Filters off-topic questions

## 🔧 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Set up environment
cp .env.example .env.local
# Add your GROQ_API_KEY (free from console.groq.com)

# 3. Run development server
npm run dev

# 4. Open browser
http://localhost:3000
```

**Setup Time:** 5 minutes
